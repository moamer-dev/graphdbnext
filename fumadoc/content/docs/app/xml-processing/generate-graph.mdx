# Generate Graph from XML

This guide covers how to generate actual graph data from XML files using your model schema, tools, and actions. Unlike schema creation, graph generation requires XML data, executable workflows, and transformation rules.

## Understanding Graph Generation

### Schema vs Graph Generation

**Schema Creation** (separate process):
- Define nodes and relationships
- Configure properties and constraints
- No XML or execution required
- Static structure definition

**Graph Generation** (this guide):
- Requires XML data source
- Uses executable tools and actions
- Creates actual graph instances
- Dynamic data processing

### Generation Requirements

To generate graphs from XML, you need:

1. **Model Schema**: Nodes and relationships structure
2. **XML Data**: Source XML file to process
3. **Tools**: Data processing and transformation tools
4. **Actions**: Workflow control and execution actions
5. **Root Node**: Starting point for XML traversal

## Access Graph Generation

### From XML Import Wizard

After completing the XML Import Wizard:

1. **Complete Wizard**: Finish all 5 wizard steps
2. **Generate Model**: Create initial schema from XML
3. **Redirect to Builder**: Automatically redirected to Plexus Builder
4. **Continue Workflow**: Build executable workflow for graph generation

### From Model Header

For existing models:

1. **Open Model**: Navigate to your model in Plexus Builder
2. **Upload XML**: Use XML upload in model header
3. **Generate Workflow**: Build tools and actions workflow
4. **Execute Generation**: Run workflow to generate graph
