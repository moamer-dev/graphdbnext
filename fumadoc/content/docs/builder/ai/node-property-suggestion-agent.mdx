# Node Property Suggestion Agent

The Node Property Suggestion Agent is an AI-powered assistant that analyzes graph nodes and suggests appropriate properties based on semantic meaning, domain knowledge, and graph database best practices.

## Purpose

The agent helps users design comprehensive node schemas by suggesting relevant properties that capture the semantic meaning and data requirements of different node types in research-oriented graph databases.

## Key Capabilities

### Semantic Analysis
- **Domain Understanding**: Analyzes node labels and types to understand semantic context
- **Research Domain Expertise**: Specialized knowledge for academic, bibliographic, and research data
- **Pattern Recognition**: Identifies common property patterns for similar node types

### Property Suggestions
- **Semantic Naming**: Suggests meaningful property names (e.g., "name", "email", "publicationDate")
- **Type Recommendations**: Determines appropriate data types (string, number, boolean, date, array, object)
- **Requirement Analysis**: Identifies which properties should be required vs optional
- **Domain-Specific Properties**: Suggests properties relevant to specific research domains

### Best Practices Integration
- **Graph Database Standards**: Follows graph database property naming and design conventions
- **Normalization Guidance**: Recommends property structures that support efficient querying
- **Extensibility Considerations**: Suggests properties that support future schema evolution

## Input Requirements

### Node Analysis Context
The agent requires information about:
- **Node Label/Type**: The semantic type of the node (e.g., "Person", "Publication", "Institution")
- **Existing Properties**: Current node properties (if any)
- **Domain Context**: Research domain or application area
- **Relationship Context**: How the node connects to other nodes

### Usage Scenarios
- **New Node Creation**: When adding new node types to the schema
- **Schema Enhancement**: When improving existing node definitions
- **Domain Adaptation**: When adapting schemas for specific research domains

## Output Structure

### Property Suggestions
```typescript
interface PropertySuggestion {
  key: string                    // Property name
  type: 'string' | 'number' | 'boolean' | 'date' | 'array' | 'object'
  required?: boolean            // Whether property is required
  description?: string          // Property description and purpose
}

interface NodePropertySuggestion {
  suggestions: PropertySuggestion[]     // General suggestions
  recommended?: PropertySuggestion[]     // Highly recommended properties
}
```

### Response Categories
- **General Suggestions**: Broad set of relevant properties (10+ suggestions)
- **Recommended Properties**: Core properties that are typically essential
- **Property Descriptions**: Clear explanations of each property's purpose
- **Type Justification**: Reasoning behind data type recommendations

## Configuration and Usage

### Agent Initialization
```typescript
import { NodePropertySuggestionAgent } from '@plexus/builder/ai/agents'

const agent = new NodePropertySuggestionAgent({
  model: chatModel,
  settings: aiSettings
})
```

### Suggestion Request
```typescript
const suggestions = await agent.suggestProperties({
  nodeLabel: "Person",
  nodeType: "AcademicResearcher",
  existingProperties: ["name", "email"],
  domain: "bibliographic"
})
```

### Property Design

- **Future Extensibility**: Design property structures that can evolve

### Domain Considerations
