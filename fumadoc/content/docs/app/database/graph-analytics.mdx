# Graph Analytics

The Graph Analytics Dashboard provides powerful tools for analyzing your graph database structure and patterns. Gain insights into node distributions, relationship patterns, and centrality metrics to understand your data better.

## Accessing Graph Analytics

### Navigation
- **Path**: Dashboard → Database → Analytics
- **URL**: `/dashboard/database/analytics`
- **Requirements**: Connected graph database with data

### Dashboard Overview
- **Real-time Data**: Analytics update with current database state
- **Interactive Tabs**: Navigate between different analysis views
- **Visual Indicators**: Charts and progress bars for data visualization
- **Export Options**: Save analytics results for reports

## Analytics Dashboard Interface

### Header Controls

#### Dashboard Actions
- **Refresh Button**: Update analytics with latest data
- **Loading Indicator**: Visual feedback during data processing
- **Error Handling**: Clear error messages with retry options
- **Auto-refresh**: Manual refresh for latest statistics

## Overview Tab

### Summary Statistics

#### Top Node Labels
- **Label Ranking**: Shows top 5 most common node labels
- **Count Display**: Exact node count for each label
- **Percentage Distribution**: Relative percentage of total nodes
- **Visual Indicators**: Icons for visual recognition

#### Top Relationship Types
- **Type Ranking**: Shows top 5 most common relationship types
- **Count Display**: Exact relationship count for each type
- **Percentage Distribution**: Relative percentage of total relationships
- **Visual Indicators**: Icons for visual recognition

### Overview Features
- **Quick Insights**: Immediate understanding of graph structure
- **Comparative Analysis**: Compare node and relationship distributions
- **Visual Hierarchy**: Most important elements highlighted
- **Summary Cards**: Organized display of key metrics

## Node Distribution Tab

### Detailed Node Analysis

#### Distribution Table
- **Complete Listing**: All node labels with counts
- **Percentage Bars**: Visual representation of distribution
- **Sorting**: Labels ordered by count (highest first)
- **Formatting**: Number formatting for large counts

#### Node Label Metrics
- **Label Name**: Exact node label from database
- **Node Count**: Total nodes with this label
- **Percentage**: Percentage of total nodes
- **Visual Progress**: Bar chart representation

### Distribution Analysis

#### Visual Features
- **Progress Bars**: Horizontal bars showing relative distribution
- **Color Coding**: Consistent color scheme for visualization
- **Responsive Tables**: Tables adapt to content length

## Degree Centrality Tab

### Centrality Analysis

#### Centrality Metrics
- **Node Identification**: Unique node IDs for centrality analysis
- **Label Information**: All labels associated with each node
- **Degree Measurements**: In-degree, out-degree, and total degree
- **Ranking**: Nodes ordered by total degree (highest first)

#### Degree Types
- **In Degree**: Number of incoming relationships
- **Out Degree**: Number of outgoing relationships
- **Total Degree**: Sum of in-degree and out-degree
- **Centrality Ranking**: Relative importance ranking

### Centrality Insights

#### Importance Analysis
- **Hub Identification**: Find most connected nodes
- **Critical Nodes**: Identify nodes with high connectivity
- **Network Structure**: Understand overall network topology
- **Influence Mapping**: Map influential nodes in the graph

#### Analytical Applications
