# Database Management

The Plexus Database Management interface provides comprehensive tools for managing, querying, and analyzing your graph database. Whether you're using Memgraph or Neo4j, this interface gives you full control over your graph data with powerful features for exploration, manipulation, and analytics.

## Accessing Database Management

### Navigation
- **Path**: Dashboard → Database
- **URL**: `/dashboard/database`
- **Requirements**: Graph database connection configured

### Database Support
- **Memgraph**: High-performance graph database
- **Neo4j**: Industry-standard graph database
- **Automatic Detection**: System detects your configured database type
- **Connection Status**: Real-time connection monitoring

## System Status Overview

### Connection Monitoring

#### Status Indicators
- **Connection State**: Shows Connected/Disconnected status
- **Real-time Updates**: Automatic status refresh
- **Manual Refresh**: Manual status check capability
- **Error Handling**: Clear error messages for connection issues

#### Database Statistics
- **Node Count**: Total number of nodes in the database
- **Relationship Count**: Total number of relationships
- **Node Labels**: Number of distinct node labels
- **Live Updates**: Statistics update in real-time

### Quick Import

#### File Upload
- **JSON Support**: Import graph data from JSON files
- **Validation**: File format validation before import

#### Import Process
1. **Select File**: Click upload area or drag JSON file
2. **Validation**: System validates JSON structure
3. **Import**: Data is loaded into graph database
4. **Confirmation**: Success notification with import details
