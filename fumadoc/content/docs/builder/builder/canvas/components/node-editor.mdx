# Node Editor

The Node Editor is your primary interface for fine-tuning individual graph nodes, managing properties, and configuring semantic mappings using the TIB terminology service. It provides comprehensive tools for configuring every aspect of graph nodes in your schema.

## Overview

The Node Editor enables you to:
- **Configure Basic Properties**: Edit node labels, types, and group assignments
- **Set Root Nodes**: Designate workflow execution starting points
- **Semantic Enrichment**: Map nodes to TIB terminology service classes and properties
- **Manage Properties**: Add, edit, and remove node properties
- **View XML Details**: Examine source XML structure and statistics
- **Get TIB Suggestions**: Receive standardized terminology recommendations

## Key Features

### Header Controls
- **Focus Node**: Center the selected node on the canvas for better visibility
- **Show/Hide Others**: Toggle visibility of unconnected nodes to reduce clutter
- **Close Editor**: Return to the main canvas view

### Basic Properties
- **Node Label**: Edit the display name that appears on the canvas
- **Node Type**: Define the node type for categorization and organization
- **Group Assignment**: Organize nodes into logical groups for better management
- **Root Node Toggle**: Set the starting point for workflow execution

### Semantic Enrichment with TIB
- **TIB Class Selection**: Map nodes to standardized terminology classes
- **TIB Property Mapping**: Connect node properties to standard semantic properties
- **Real-Time Lookup**: Search TIB terminology service as you type
- **Contextual Suggestions**: Get relevant terms based on node context and type

### XML Element Details
- **Type Statistics**: View element counts, attributes, and structural information
- **Children Elements**: See child element types and their frequencies
- **Parent Element**: Understand the hierarchical context in the XML structure
- **Ancestor Chain**: View the complete element path from root to current element

### Property Management
- **Add Properties**: Create new custom properties for your nodes
- **Edit Values**: Modify existing property values with validation
- **Delete Properties**: Remove unnecessary properties to keep your schema clean
- **Type Validation**: Ensure property data integrity and consistency

## User Workflow

### Step 1: Select Node
Click on any node in the canvas to open the Node Editor. The editor will display:
- Current node properties and configuration
- XML element information if available
- Semantic mapping status
- Property validation indicators

### Step 2: Configure Basic Properties
Set up the fundamental node characteristics:
1. **Edit Label**: Change the display name for clarity
2. **Set Type**: Define the node type for categorization
3. **Assign Group**: Organize nodes into logical groups
4. **Set Root Node**: Designate as workflow starting point if needed

### Step 3: Enable Semantic Mode
Activate TIB terminology service integration:
1. **Toggle Semantic Mode**: Enable TIB service access
2. **Select Ontology**: Choose appropriate terminology set from TIB
3. **Map to Standards**: Connect node to TIB classes and properties
4. **Validate Mapping**: Ensure semantic correctness and consistency

### Step 4: Configure Properties
Add and manage node properties:
1. **Add Properties**: Create new custom properties as needed
2. **Set Values**: Define property values with proper data types
3. **Apply Validation**: Ensure data integrity and consistency
4. **Test Configuration**: Validate with sample data if available

### Step 5: Review XML Data
Examine the source XML structure:
1. **View Statistics**: Check element counts and structure
2. **Examine Children**: Understand child element relationships
3. **Review Hierarchy**: See parent and ancestor relationships
4. **Validate Mapping**: Ensure XML to graph mapping is correct

### Step 6: Apply TIB Suggestions
Use standardized terminology recommendations:
1. **Review Suggestions**: Consider TIB terminology recommendations
2. **Apply Changes**: Accept relevant semantic mappings
3. **Customize**: Modify suggestions to fit your specific needs
4. **Validate**: Test final configuration with sample data
