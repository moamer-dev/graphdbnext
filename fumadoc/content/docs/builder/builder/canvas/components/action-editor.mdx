# Action Editor

The Action Editor provides a specialized interface for configuring data transformation actions that process and manipulate XML data within workflows. It offers comprehensive property mapping, API integration, group management, and testing capabilities to ensure your actions transform data correctly.

## Overview

The Action Editor enables you to:
- **Configure Action Types**: Set up node, property, and relationship actions
- **Map Data Properties**: Define data transformation rules
- **Integrate with APIs**: Connect actions to upstream tool outputs
- **Manage Action Groups**: Organize related actions efficiently
- **Test Transformations**: Validate actions with sample data and preview results

## Action Categories

### Node Actions
Operations that create and manage graph nodes:

#### Create Node Action
- **Node Creation**: Generate new graph nodes
- **Property Assignment**: Set initial node properties
- **Type Definition**: Define node types
- **Relationship Creation**: Establish initial connections

#### Update Node Action
- **Property Modification**: Update existing node properties
- **Type Changes**: Modify node types
- **Data Validation**: Ensure data integrity
- **Conditional Updates**: Update based on conditions

#### Delete Node Action
- **Node Removal**: Delete nodes from graph
- **Conditional Deletion**: Remove based on criteria
- **Cleanup**: Handle orphaned relationships
- **Validation**: Ensure graph consistency

#### Clone Node Action
- **Node Duplication**: Create node copies
- **Property Inheritance**: Copy or modify properties
- **Relationship Cloning**: Duplicate connections
- **Customization**: Modify cloned nodes

### Property Actions
Operations that manipulate node and relationship properties:

#### Set Property Action
- **Property Assignment**: Set property values
- **Type Conversion**: Convert data types
- **Validation**: Ensure value correctness
- **Default Handling**: Set default values

#### Copy Property Action
- **Property Transfer**: Copy between nodes
- **Source Selection**: Choose source properties
- **Target Mapping**: Define destination properties
- **Type Handling**: Manage type conversions

#### Format Property Action
- **Data Formatting**: Format property values
- **Date Formatting**: Handle date/time formats
- **Number Formatting**: Format numeric values
- **String Operations**: Text manipulation

#### Merge Properties Action
- **Property Combination**: Merge multiple properties
- **Separator Configuration**: Define merge separators
- **Priority Rules**: Set property precedence
- **Conflict Resolution**: Handle value conflicts

### Relationship Actions
Operations that manage connections between nodes:

#### Create Relationship Action
- **Connection Creation**: Establish node relationships
- **Type Definition**: Define relationship types
- **Property Assignment**: Set relationship attributes
- **Cardinality Management**: Handle connection constraints

#### Update Relationship Action
- **Property Modification**: Update relationship properties
- **Type Changes**: Modify relationship types
- **Direction Changes**: Reverse relationship direction
- **Validation**: Ensure relationship integrity

#### Delete Relationship Action
- **Connection Removal**: Delete relationships
- **Conditional Deletion**: Remove based on criteria
- **Cleanup**: Handle orphaned nodes
- **Validation**: Ensure graph consistency
