# Query Interface

The Plexus Query Interface provides multiple powerful methods for querying your graph database, from pre-built query libraries to AI-powered natural language queries. Whether you're a beginner or an expert, there's a query method that fits your needs.

## Accessing Query Interface

### Navigation
- **Path**: Dashboard → Database → Querying
- **URL**: `/dashboard/database/queries`
- **Requirements**: Connected graph database with data

### Interface Overview
- **Multi-Mode Support**: Four different query methods
- **Resizable Panels**: Adjustable workspace layout
- **Real-time Results**: Instant query execution and results
- **AI Integration**: Intelligent query assistance

## Query Methods Overview

### Available Query Modes

#### Library Mode
- **Purpose**: Use pre-built, tested queries
- **Best For**: Quick access to common query patterns
- **Features**: Categorized queries, search, execution
- **Skill Level**: Beginner to Intermediate

#### Query Builder Mode
- **Purpose**: Build queries visually without writing code
- **Best For**: Users learning Cypher or complex queries
- **Features**: Visual node/relationship selection, condition building
- **Skill Level**: Beginner to Advanced

#### Cypher Editor Mode
- **Purpose**: Write and execute raw Cypher queries
- **Best For**: Expert users and complex custom queries
- **Features**: Syntax highlighting, code completion, validation
- **Skill Level**: Intermediate to Expert

#### AI Agent Mode
- **Purpose**: Ask questions in natural language
- **Best For**: Users who prefer conversational queries
- **Features**: Natural language processing, query generation
- **Skill Level**: All levels (with AI enabled)
