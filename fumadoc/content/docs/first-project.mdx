# First Project

Learn how to create your first project in GraphDBNext and start working with graph databases.

## Creating a New Project

1. Sign in to your GraphDBNext account
2. Click the "New Project" button
3. Enter project details:
   - Project name
   - Description
   - Database type
4. Click "Create Project"

## Setting Up Database Connection

### Connecting to Neo4j

1. Navigate to the "Connections" tab
2. Click "Add Connection"
3. Select "Neo4j" as the database type
4. Enter connection details:
   - Connection URL
   - Username
   - Password
   - Database name
5. Test the connection
6. Save the connection

### Connecting to Other Databases

GraphDBNext supports multiple graph database types. Select your database type and follow the specific connection instructions.

## Creating Your First Schema

### Using the Visual Schema Builder

1. Go to the "Schema" tab
2. Click "Create New Schema"
3. Use the visual builder to:
   - Add node types
   - Define properties
   - Create relationships
4. Save your schema

### Importing Existing Schema

If you have an existing schema:

1. Click "Import Schema"
2. Choose import method:
   - Upload schema file
   - Paste schema definition
   - Import from database
3. Review and confirm import

## Working with Data

### Adding Data Manually

1. Navigate to the "Data" tab
2. Click "Add Node"
3. Select node type
4. Enter properties
5. Save the node

### Importing Data

#### CSV Import

1. Prepare your CSV file with proper headers
2. Click "Import Data"
3. Select "CSV Import"
4. Upload your file
5. Map columns to properties
6. Start import

#### JSON Import

1. Format your data as JSON
2. Use the JSON import tool
3. Validate the structure
4. Import the data

## Building Your First Query

### Using the Visual Query Builder

1. Go to the "Query" tab
2. Select "Visual Builder"
3. Drag and drop elements:
   - Start with a node type
   - Add relationships
   - Apply filters
4. Preview the query
5. Execute the query

### Writing Cypher Queries

If you're familiar with Cypher:

1. Select "Cypher Editor"
2. Write your query
3. Use syntax highlighting and autocomplete
4. Execute the query

## Visualizing Results

### Graph Visualization

1. Execute a query
2. View results in the graph visualization
3. Interact with the visualization:
   - Zoom and pan
   - Select nodes and edges
   - View properties

### Table View

Switch to table view for:

- Detailed data inspection
- Export functionality
- Bulk operations

## Saving Your Work

### Saving Queries

1. Click "Save Query"
2. Enter query name and description
3. Organize into folders
4. Set sharing permissions

### Exporting Results

Export your query results in various formats:

- CSV
- JSON
- GraphML
- Custom formats
