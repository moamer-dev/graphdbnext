# Frequently Asked Questions

Find answers to common questions about GraphDBNext.

## General Questions

### What is GraphDBNext?

GraphDBNext is a modern graph database management platform that provides tools for creating, visualizing, and analyzing graph databases. It offers both visual and code-based interfaces for working with graph data.

### Who is GraphDBNext for?

GraphDBNext is designed for:
- Developers working with graph databases
- Data scientists analyzing network data
- Database administrators managing graph systems
- Business analysts exploring connected data

### What graph databases are supported?

GraphDBNext supports multiple graph database systems:
- Neo4j
- Amazon Neptune
- Azure Cosmos DB (Gremlin API)
- ArangoDB
- And more through custom connectors

## Installation and Setup

### What are the system requirements?

- **Node.js**: Version 18 or higher
- **PostgreSQL**: For metadata storage
- **Memory**: Minimum 4GB RAM (8GB recommended)
- **Storage**: 10GB available space

### Can I run GraphDBNext in Docker?

Yes, GraphDBNext provides Docker containers for easy deployment. Use the provided docker-compose.yml file to get started.

### How do I update GraphDBNext?

1. Backup your data
2. Pull the latest version
3. Run database migrations
4. Restart the application

### What query languages are supported?

## Troubleshooting

### Why is my query running slowly?

Common causes and solutions:
- Missing indexes: Create appropriate indexes
- Large result sets: Add LIMIT clauses
- Complex patterns: Break into simpler queries
- Network latency: Check connection settings

### How do I reset my password?

1. Go to the login page
2. Click "Forgot Password"
3. Enter your email address
4. Follow the reset link in your email
5. Create a new password

### Why can't I connect to my database?

Check the following:
- Database server is running
- Connection credentials are correct
- Network connectivity exists
- Firewall settings allow connections
- Database user has proper permissions
