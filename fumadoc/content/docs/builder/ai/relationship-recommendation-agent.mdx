# Relationship Recommendation Agent

The Relationship Recommendation Agent is an AI-powered assistant that analyzes pairs of nodes and suggests appropriate relationship types, cardinality, and properties based on semantic meaning, domain knowledge, and graph database best practices.

## Purpose

The agent helps users design meaningful relationships between nodes by suggesting semantically appropriate connection types, determining optimal cardinality, and recommending relationship properties that capture the nature of the connections in research-oriented graph databases.

## Key Capabilities

### Semantic Relationship Analysis
- **Node Pair Analysis**: Examines two nodes to understand their semantic relationship
- **Domain Expertise**: Applies specialized knowledge for academic, bibliographic, and research domains
- **Directional Understanding**: Considers the direction and meaning of relationships
- **Contextual Relevance**: Analyzes how node properties and contexts influence relationships

### Relationship Type Suggestions
- **Semantic Naming**: Suggests meaningful relationship types (e.g., "AUTHORED", "PUBLISHED_IN", "AFFILIATED_WITH")
- **Domain-Specific Types**: Provides relationship types relevant to specific research domains
- **Variety of Perspectives**: Suggests relationships from different viewpoints and use cases
- **Standard Compliance**: Follows standard relationship naming conventions

### Cardinality and Properties
- **Cardinality Analysis**: Determines appropriate cardinality (one-to-one, one-to-many, many-to-many)
- **Property Recommendations**: Suggests relevant relationship properties
- **Confidence Scoring**: Provides confidence scores for each recommendation
- **Reasoning Explanations**: Offers clear explanations for relationship suggestions

## Input Requirements

### Node Pair Context
The agent requires information about:
- **Source Node**: Label, type, and properties of the source node
- **Target Node**: Label, type, and properties of the target node
- **Existing Relationships**: Current relationships between the nodes
- **Domain Context**: Research domain or application area
- **Use Case Scenarios**: Intended use cases for the relationship

### Analysis Scenarios
- **New Relationship Design**: When creating connections between node types
- **Schema Enhancement**: When improving existing relationship definitions
- **Domain Adaptation**: When adapting relationships for specific research domains

## Output Structure

### Relationship Suggestions
```typescript
interface RelationshipSuggestion {
  type: string                    // Relationship type name
  cardinality: 'one-to-one' | 'one-to-many' | 'many-to-many'
  properties?: Array<{
    name: string
    type: 'string' | 'number' | 'boolean' | 'date'
    description?: string
  }>
  confidence: number              // Confidence score (0-1)
  reasoning: string               // Explanation for the suggestion
}

interface RelationshipRecommendation {
  suggestions: RelationshipSuggestion[]     // Multiple relationship options
  recommended?: RelationshipSuggestion       // Top recommendation
}
```

### Response Categories
- **Multiple Options**: Provides 10+ relationship type suggestions
- **Top Recommendation**: Highlights the most appropriate relationship type
- **Confidence Scores**: Indicates confidence level for each suggestion
- **Detailed Reasoning**: Explains the logic behind each recommendation

## Configuration and Usage

### Agent Initialization
```typescript
import { RelationshipRecommendationAgent } from '@plexus/builder/ai/agents'

const agent = new RelationshipRecommendationAgent({
  model: chatModel,
  settings: aiSettings
})
```

### Relationship Request
```typescript
const recommendations = await agent.suggestRelationships({
  sourceNode: {
    label: "Person",
    type: "Author",
    properties: ["name", "email", "orcid"]
  },
  targetNode: {
    label: "Publication", 
    type: "AcademicPaper",
    properties: ["title", "publicationDate", "doi"]
  },
  domain: "bibliographic"
})
```
