# Relationship Editor

The Relationship Editor provides a specialized interface for configuring connections between nodes in your graph schema. It offers comprehensive tools for defining relationship types, setting cardinality, and integrating with TIB terminology service for semantic consistency.

## Overview

The Relationship Editor enables you to:
- **Configure Connection Types**: Define how nodes are related
- **Set Cardinality Rules**: Establish one-to-one, one-to-many relationships
- **Map to TIB Terminology**: Use standardized relationship terminology
- **Manage Properties**: Add relationship-specific attributes
- **Validate Connections**: Ensure semantic consistency

## User Workflow

### Step 1: Select Relationship
Click on any connection line in the canvas to open the Relationship Editor. The editor will display:

- **Source Node**: The originating node
- **Target Node**: The destination node
- **Current Type**: Existing relationship type
- **Configuration Status**: Validation indicators

### Step 2: Configure Basic Settings
Set up the fundamental relationship parameters:

1. **Relationship Type**: Choose from available types or create custom
2. **Direction**: Set the flow direction
3. **Label**: Edit the display name
4. **Description**: Add explanatory notes

### Step 3: Set Cardinality
Define the connection constraints:

- **Select Cardinality Type**: One-to-one, one-to-many, many-to-many
- **Configure Rules**: Set specific constraints
- **Add Conditions**: Context-dependent requirements
- **Test Scenarios**: Validate with sample data

### Step 4: Enable Semantic Mode
Activate TIB terminology integration:

1. **Toggle Semantic Mode**: Enable TIB service access
2. **Select Ontology**: Choose appropriate terminology set
3. **Map to Standards**: Connect to TIB relationship types
4. **Validate Mapping**: Ensure semantic correctness

### Step 5: Configure Properties
Add relationship-specific attributes:

- **Add Properties**: Create new attributes
- **Set Types**: Define data types and constraints
- **Default Values**: Establish automatic assignments
- **Validation Rules**: Set up data validation

### Step 6: Apply Recommendations
Use intelligent suggestions:

- **Review Suggestions**: Consider AI-powered recommendations
- **Apply Changes**: Accept relevant improvements
- **Customize**: Modify suggestions as needed
- **Validate**: Test final configuration
