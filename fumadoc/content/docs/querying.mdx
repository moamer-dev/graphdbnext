# Querying

Master the art of querying graph databases using GraphDBNext's powerful query tools.

## Query Methods

GraphDBNext offers multiple ways to query your graph data:

### Visual Query Builder

The visual query builder allows you to create complex queries without writing code:

- Drag-and-drop interface
- Real-time query preview
- Visual relationship mapping
- Automatic Cypher generation

### Cypher Editor

For advanced users who prefer writing queries directly:

- Syntax highlighting
- Auto-completion
- Error checking
- Query validation

### Query Templates

Pre-built templates for common query patterns:

- Path finding
- Neighbor analysis
- Centrality measures
- Pattern matching

## Visual Query Builder

### Getting Started

1. Navigate to the Query tab
2. Select "Visual Builder"
3. Start with a node type

### Building Queries

#### Adding Nodes

1. Drag a node type from the palette
2. Place it on the canvas
3. Set node properties and filters

#### Creating Relationships

1. Connect nodes with relationship types
2. Define relationship properties
3. Set cardinality and direction

#### Applying Filters

1. Click on nodes or relationships
2. Add filter conditions
3. Use logical operators (AND, OR, NOT)

#### Query Preview

The generated Cypher query updates in real-time as you build visually.

## Query Optimization

### Performance Tips

1. **Use labels effectively**: Always specify node labels when possible
2. **Limit result sets**: Use LIMIT to restrict large result sets
3. **Index properties**: Create indexes on frequently queried properties
4. **Avoid Cartesian products**: Be careful with cross-product patterns

## Troubleshooting

### Common Issues

**Slow queries**
- Check for missing indexes
- Review query patterns
- Use EXPLAIN to analyze

**Memory errors**
- Add LIMIT clauses
- Break complex queries into smaller parts
- Use pagination

**Syntax errors**
- Use the query validator
- Check bracket matching
- Review Cypher documentation
