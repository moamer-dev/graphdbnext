# Workflow Generation Agent

The Workflow Generation Agent is an advanced AI assistant that generates complete workflows for processing XML data and transforming it into graph database structures. It understands XML parsing patterns, graph database operations, and common scholarly data processing workflows.

## Purpose

The agent automates the creation of data transformation workflows by analyzing XML structures and generating optimized workflow configurations that use appropriate tools and actions to convert XML data into meaningful graph representations.

## Key Capabilities

### XML Structure Understanding
- **XML Pattern Recognition**: Identifies common XML patterns and structures
- **Scholarly Data Expertise**: Specialized knowledge of TEI, edXML, and other academic XML formats
- **Hierarchy Analysis**: Understands XML element hierarchies and relationships
- **Attribute Processing**: Analyzes XML attributes and their significance

### Workflow Generation
- **Tool Selection**: Chooses appropriate control flow tools (If/Switch, Delay, HTTP, Webhook)
- **Action Optimization**: Selects specialized actions over generic ones when available
- **Logical Structuring**: Creates logically structured and efficient workflows
- **Error Handling**: Incorporates error handling and edge case management

### Specialized Action Preference
- **Token Node Creation**: Uses `action:create-token-nodes` for text tokenization
- **Annotation Processing**: Uses `action:create-reference` for scholarly annotations
- **Reference Handling**: Uses `action:create-reference-chain` for reference processing
- **Deferred Creation**: Uses `action:create-node-with-lookup` for complex node creation

## Input Requirements

### XML Structure Analysis
The agent requires:
- **XML Schema**: Sample XML structure or DTD/XSD definitions
- **Domain Context**: Research domain and data type information
- **Target Schema**: Desired graph database schema

### Workflow Requirements
- **Data Volume**: Expected XML data volume and complexity

## Configuration and Usage

### Agent Initialization
```typescript
import { WorkflowGenerationAgent } from '@plexus/builder/ai/agents'

const agent = new WorkflowGenerationAgent({
  model: chatModel,
  settings: aiSettings
})
```

### Workflow Generation Request
```typescript
const workflow = await agent.generateWorkflow({
  xmlStructure: `
    <teiCorpus>
      <TEI>
        <teiHeader>
          <fileDesc>
            <titleStmt>
              <title>Document Title</title>
              <author>Author Name</author>
            </titleStmt>
          </fileDesc>
        </teiHeader>
        <text>
          <body>
            <div type="chapter">
              <p>Some text content</p>
            </div>
          </body>
        </text>
      </TEI>
    </teiCorpus>
  `,
  targetSchema: {
    nodes: ["Document", "Author", "Chapter", "Paragraph"],
    relationships: ["AUTHORED", "CONTAINS", "HAS_CHAPTER"]
  },
  domain: "tei_documents"
})
```

## Specialized Action Usage

### Token Processing
```typescript
// For text tokenization
{
  type: "action:create-token-nodes",
  config: {
    parentNodeLabel: "TextContent",
    tokenNodeLabel: "Token",
    relationshipType: "CONTAINS_TOKEN",
    splitBy: " ",  // Character-level for detailed analysis
    structure: "chained"  // Linked list of tokens
  }
}
```

### Annotation Processing
```typescript
// For scholarly annotations
{
  type: "action:create-reference",
  config: {
    referenceAttribute: "target",

}
```
