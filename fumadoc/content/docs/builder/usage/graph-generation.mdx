# Graph Generation

Graph Generation in Plexus Builder enables you to transform XML data into meaningful graph structures through visual workflow design and automated processing. This powerful feature combines the XML Import Wizard with the Workflow Builder to create end-to-end data transformation pipelines.

## Overview

The Graph Generation process allows you to:
- **Import XML Data**: Upload and analyze XML documents using the import wizard
- **Design Workflows**: Create visual workflows to process XML elements
- **Transform Data**: Convert XML structures into graph nodes and relationships
- **Generate Graphs**: Produce complete graph databases from XML sources
- **Optimize Processing**: Fine-tune workflows for performance and quality

## The Graph Generation Pipeline

### Step 1: XML Import and Analysis

#### XML Upload
1. **Upload Files**: Drag and drop or browse to select XML files
2. **Format Validation**: Automatic validation of XML structure and format
3. **File Information**: Display file details, size, and element count
4. **Supported Formats**: TEI, edXML, and custom XML formats

#### Analysis Rules Configuration
1. **Rule Setup**: Configure analysis rules for XML processing
2. **Element Selection**: Choose which XML elements to process
3. **Attribute Mapping**: Define how XML attributes map to properties
4. **AI Assistance**: Use AI to suggest optimal analysis rules

#### Structure Analysis
1. **Automatic Analysis**: System analyzes XML structure and relationships
2. **Element Detection**: Identify all XML elements and their properties
3. **Hierarchy Mapping**: Map parent-child relationships in XML
4. **Pattern Recognition**: Identify recurring patterns and structures

### Step 2: Element Mapping Configuration

#### Visual Mapping Interface
1. **Dual Panel View**: XML structure on left, mapping configuration on right
2. **Element Selection**: Click to select XML elements for mapping
3. **Node Assignment**: Assign XML elements to graph node types
4. **Property Mapping**: Map XML attributes to node properties

#### Semantic Enrichment
1. **TIB Integration**: Connect to terminology service for standard concepts
2. **AI Mapping Assistant**: Get AI suggestions for optimal mappings
3. **Semantic Types**: Assign semantic categories to nodes
4. **Property Standardization**: Use standard property definitions

#### Relationship Configuration
1. **Relationship Detection**: Automatically infer relationships from XML hierarchy
2. **Manual Definition**: Manually define specific relationships
3. **Cardinality Setup**: Configure relationship cardinality
4. **Property Assignment**: Add properties to relationships

### Step 3: Workflow Design

#### Visual Workflow Builder
1. **Tool Palette**: Drag control flow tools onto the canvas
2. **Action Library**: Add data transformation actions
3. **Connection Logic**: Connect tools and actions to create processing flow
4. **Configuration Panels**: Configure parameters for each component

#### Essential Workflow Components

##### Control Flow Tools
- **If Tool**: Conditional branching based on element properties
- **Switch Tool**: Multi-way branching based on values
- **Delay Tool**: Rate limiting and timing control
- **Fetch API**: Retrieve data from external services
- **HTTP Request**: Generic HTTP/HTTPS requests
- **Webhook**: Send notifications to external systems

##### Data Actions
- **Create Node**: Create graph nodes from XML elements
- **Create Text Node**: Extract text into dedicated nodes
- **Create Token Nodes**: Break text into individual tokens
- **Create Annotation Nodes**: Process scholarly annotations
- **Create Deferred Node**: Find or create nodes with lookup
- **Set Property**: Assign values to node properties
- **Create Relationship**: Establish connections between nodes

#### Workflow Examples

##### Simple TEI Document Processing
```
Root Tool (teiCorpus) 
  → If Tool (has teiHeader)
    → Create Node (Document)
    → Set Property (title from titleStmt)
  → Create Node (TextContent) from text/body
  → Create Token Nodes from paragraphs
  → Create Relationships (CONTAINS)
```

##### Bibliographic Data Processing
```
Root Tool (records)
  → Switch Tool (record type)
    → Case "article"
      → Create Node (Article)
      → Create Node (Author) with lookup
      → Create Relationship (AUTHORED)
    → Case "book"
      → Create Node (Book)
      → Create Node (Publisher)
      → Create Relationship (PUBLISHED_BY)
```

## Advanced Workflow Features

### Conditional Processing

#### Complex Logic with If Tool
```typescript
// Example: Process different element types
{
  type: "tool:if",
  config: {
    conditionGroups: [{
      conditions: [{
        field: "elementName",
        operator: "equals",
        value: "persName"
      }]
    }]
  }
}
```

#### Multi-way Branching with Switch Tool
```typescript
// Example: Handle different document types
{
  type: "tool:switch",
  config: {
    switchSource: "attribute",
    switchAttributeName: "type",
    switchCases: [
      { matchValue: "article", caseLabel: "ProcessArticle" },
      { matchValue: "book", caseLabel: "ProcessBook" }
    ]
  }
}
```
