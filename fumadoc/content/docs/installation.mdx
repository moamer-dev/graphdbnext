# Installation

This guide will help you install and set up GraphDBNext on your system.

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js** (version 18 or higher)
- **PostgreSQL** (for metadata storage)
- **Docker** (optional, for containerized deployment)

## Installation Methods

### Method 1: Clone from Repository

Use git to clone the repository and install dependencies:

1. Clone the repository
2. Navigate to the project directory
3. Run npm install

### Method 2: Using Docker

Use Docker Compose to start the application with the command: docker-compose up -d

### Method 3: Download Release

1. Download the latest release from our GitHub releases page
2. Extract the archive
3. Run npm install

## Environment Setup

Create a `.env.local` file in the root directory with your database URL and authentication settings.

## Database Setup

1. Start PostgreSQL service
2. Create a new database named "graphdbnext"
3. Run database migrations using Prisma
4. Optionally seed the database with initial data

## Running the Application

### Development Mode

Run the development server to start the application locally.

### Production Mode

Build and start the production server.

## Verification

To verify your installation:

1. Open your browser and navigate to the local application URL
2. Create an account or sign in
3. Create your first database connection

## Troubleshooting

### Common Issues

**Port already in use**
Kill the process running on the port.

**Database connection failed**
- Verify PostgreSQL is running
- Check your DATABASE_URL format
- Ensure the database exists

**Permission errors**
Fix file permissions using chmod.

### Getting Help

If you encounter issues not covered here:

- Check our FAQ page
