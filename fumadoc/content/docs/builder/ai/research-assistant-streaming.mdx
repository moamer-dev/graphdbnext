# Research Assistant Streaming

The Research Assistant Streaming is the streaming version of the Research Assistant Agent that provides real-time, incremental responses for enhanced user experience. It maintains all the capabilities of the standard Research Assistant while adding streaming functionality for more interactive and responsive conversations.

## Purpose

The streaming agent provides the same comprehensive assistance as the standard Research Assistant but with the added benefit of real-time response generation. This allows users to see responses being built incrementally, providing immediate feedback and a more natural conversational experience.

## Key Differences from Standard Agent

### Streaming Capabilities
- **Real-time Generation**: Responses are generated and displayed incrementally
- **Immediate Feedback**: Users can see responses as they're being created
- **Natural Conversation Flow**: More natural, conversational interaction experience
- **Early Interruption**: Users can intervene or redirect conversations mid-response

### Performance Benefits
- **Reduced Perceived Latency**: Users see content immediately rather than waiting for complete responses
- **Better User Experience**: More engaging and responsive interaction
- **Progressive Disclosure**: Information is revealed progressively
- **Resource Efficiency**: Can be more efficient for long, complex responses

## Core Capabilities

### Schema Design Assistance (Streaming)
- **Incremental Schema Building**: Watch schema suggestions build in real-time
- **Progressive Relationship Suggestions**: See relationship recommendations develop
- **Step-by-Step Guidance**: Receive guidance as it's being formulated
- **Interactive Design**: Interact with the design process as it unfolds

### Workflow Design Support (Streaming)
- **Real-time Workflow Construction**: See workflow suggestions build incrementally
- **Progressive Tool Selection**: Watch tool recommendations develop
- **Step-by-Step Configuration**: Receive configuration guidance progressively
- **Interactive Optimization**: Interact with optimization suggestions as they're generated

### Educational Support (Streaming)
- **Progressive Explanation**: Concepts are explained incrementally
- **Building Understanding**: See complex ideas built step by step

## Streaming Implementation

### Technical Architecture
```typescript
export async function* invokeResearchAssistantStreaming(
  model: BaseChatModel,
  settings: AISettings,
  message: string,
  conversationHistory: Array<HumanMessage | AIMessage | ToolMessage> = [],
  toolContext?: ToolExecutionContext,
  appContext?: ResearchAssistantContext
): AsyncGenerator<string, void, unknown>
```

### Usage Example
```typescript
import { ResearchAssistantAgentStreaming } from '@plexus/builder/ai/agents'

const streamingAgent = new ResearchAssistantAgentStreaming({
  model: chatModel,
  settings: aiSettings
})

// Stream responses in real-time
for await (const chunk of streamingAgent.invokeStreaming(
  "Help me design a schema for bibliographic data",
  conversationHistory,
  toolContext,
  appContext
)) {
  // Display each chunk as it arrives
  console.log(chunk)
}
```

## Integration Examples

### React Integration
```typescript
function StreamingAssistant() {
  const [response, setResponse] = useState('')
  const [isStreaming, setIsStreaming] = useState(false)

  const handleUserMessage = async (message: string) => {
    setIsStreaming(true)
    setResponse('')
    
    for await (const chunk of streamingAgent.invokeStreaming(
      message,
      conversationHistory,
      toolContext,
      appContext
    )) {
      setResponse(prev => prev + chunk)
    }
    
    setIsStreaming(false)
  }

  return (
    <div>
      <div className={isStreaming ? 'streaming' : ''}>
        {response}
      </div>
      {isStreaming && <TypingIndicator />}
    </div>
  )
}
```

### WebSocket Integration
```typescript
// Server-side streaming endpoint
app.post('/api/assistant/stream', async (req, res) => {
  res.writeHead(200, {
    'Content-Type': 'text/plain',
    'Transfer-Encoding': 'chunked'
  })

  try {
    for await (const chunk of streamingAgent.invokeStreaming(
      req.body.message,
      req.body.history,
      toolContext,
      appContext
    )) {
      res.write(chunk)
    }
  } catch (error) {
    res.write(`Error: ${error.message}`)
  } finally {
    res.end()
  }
})
```
