# XML Mapping Assistant

The XML Mapping Assistant is a specialized AI agent that analyzes XML structures (especially TEI, edXML, and other scholarly formats) and suggests intelligent mappings to graph database schemas. It combines domain expertise with semantic understanding to create optimal XML-to-graph transformations.

## Purpose

The assistant helps users bridge the gap between XML document structures and graph database schemas by providing intelligent, context-aware mapping suggestions that preserve semantic meaning while optimizing for graph database efficiency and research workflow requirements.

## Key Capabilities

### XML Structure Analysis
- **Element Understanding**: Analyzes XML elements and their semantic meaning
- **Hierarchy Recognition**: Understands XML element hierarchies and relationships
- **Attribute Processing**: Evaluates XML attributes and their significance
- **Content Analysis**: Analyzes text content and its structural role

### Semantic Mapping
- **Domain-Specific Knowledge**: Specialized expertise in TEI, edXML, and scholarly XML formats
- **Semantic Node Naming**: Suggests researcher-friendly node names (e.g., "Person" not "persName")
- **Relationship Inference**: Infers relationships based on XML hierarchy and attributes
- **Property Type Detection**: Determines appropriate property types from XML content

### Research Domain Expertise
- **TEI Elements**: Understands TEI elements like `<persName>`, `<placeName>`, `<div>`, `<p>`
- **Scholarly Patterns**: Recognizes common patterns in scholarly XML documents
- **Bibliographic Structures**: Handles bibliographic and citation structures
- **Annotation Processing**: Processes scholarly annotations and references

## Input Requirements

### XML Structure Information
The assistant requires:
- **XML Schema**: Sample XML structure or element definitions
- **Element Inventory**: List of available XML elements and attributes
- **Hierarchy Information**: Parent-child relationships between elements
- **Content Samples**: Example content for different element types

### Domain Context
- **Document Type**: Type of XML document (TEI, edXML, custom, etc.)
- **Research Domain**: Academic field or research area
- **Usage Requirements**: Intended use cases and analysis requirements
- **Target Schema**: Desired graph database schema (if available)

## Output Structure

### Mapping Suggestions
```typescript
interface RelationshipSuggestion {
  targetElement: string
  relationshipType: string
}

interface NodeSuggestion {
  elementName: string
  nodeLabel: string
  nodeType: string
  properties?: string[]
  relationships?: RelationshipSuggestion[]
}

interface XmlMappingSuggestion {
  nodes: NodeSuggestion[]
  explanation: string
  confidence?: number
}
```

### Mapping Categories
- **Element-to-Node Mappings**: Direct mapping of XML elements to graph nodes
- **Attribute-to-Property Mappings**: Mapping of XML attributes to node properties
- **Relationship Suggestions**: Inferred relationships between mapped nodes
- **Confidence Scoring**: Confidence levels for mapping suggestions

## Configuration and Usage

### Assistant Initialization
```typescript
import { XmlMappingAssistant } from '@plexus/builder/ai/agents'

const assistant = new XmlMappingAssistant({
  model: chatModel,
  settings: aiSettings
})
```

### Mapping Request
```typescript
const mappings = await assistant.suggestMappings({
  xmlStructure: {
    elements: ["teiCorpus", "TEI", "teiHeader", "fileDesc", "titleStmt", "title", "author", "text", "body", "div", "p"],
    attributes: ["xml:id", "type", "n", "corresp", "target"],
    hierarchy: {
      "teiCorpus": ["TEI"],
      "TEI": ["teiHeader", "text"],
      "teiHeader": ["fileDesc"],
      "fileDesc": ["titleStmt"],
      "titleStmt": ["title", "author"],
      "text": ["body"],
      "body": ["div"],
      "div": ["p"]
    }
  },
  domain: "tei_documents",
  targetSchema: {
    preferredNodes: ["Document", "Person", "Chapter", "Paragraph"]
  }
})
```

## XML Format Specializations

### TEI Document Processing
**Common TEI Elements**:
- `<persName>` → "Person" node with name properties
- `<placeName>` → "Place" node with location properties
- `<div>` → "Section" or "Chapter" nodes with type attributes
- `<p>` → "Paragraph" or "TextContent" nodes
- `<title>` → "title" property on appropriate nodes

**Relationship Inferences**:
- Parent-child relationships → "CONTAINS" relationships
- `<corresp>` attributes → "CORRESPONDS_WITH" relationships
- `<ref>` elements → "REFERENCES" relationships

### edXML Processing
**Educational Data Elements**:
- `<learner>` → "Student" or "Learner" nodes
- `<assessment>` → "Assessment" nodes
- `<outcome>` → "Result" or "Outcome" nodes
- `<institution>` → "Institution" nodes

**Educational Relationships**:
- Enrollment relationships → "ENROLLED_IN"
- Assessment relationships → "ASSESSED_BY"
- Completion relationships → "COMPLETED"

### Custom Scholarly XML
**Pattern Recognition**:
- Identifies scholarly document patterns
- Recognizes citation and reference structures
- Handles annotation and markup patterns
- Processes metadata structures
