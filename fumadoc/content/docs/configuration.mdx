# Configuration

This guide covers how to configure GraphDBNext for your specific environment and needs.

## Environment Variables

GraphDBNext uses several environment variables to configure its behavior. Create a `.env.local` file in the root directory of your project.

### Required Variables

- `DATABASE_URL`: PostgreSQL connection string for metadata storage
- `NEXTAUTH_SECRET`: Secret key for authentication
- `NEXTAUTH_URL`: Base URL for NextAuth.js

### Optional Variables

- `NODE_ENV`: Environment (development, production)
- `PORT`: Port number for the development server
- `REDIS_URL`: Redis connection string for caching

## Database Configuration

### PostgreSQL Setup

1. Install PostgreSQL on your system
2. Create a new database for GraphDBNext
3. Configure connection settings

### Connection String Format

Use the format: postgresql://username:password@host:port/database

Example: postgresql://postgres:password@localhost:5432/graphdbnext

## Authentication Configuration

GraphDBNext uses NextAuth.js for authentication. You can configure various authentication providers:

### Google OAuth

Set GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET environment variables.

### GitHub OAuth

Set GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET environment variables.

## Graph Database Connections

### Neo4j Configuration

To connect to Neo4j databases, configure the following:

- Connection URL: bolt://localhost:7687
- Username and password
- Database name

### Other Graph Databases

GraphDBNext supports various graph database systems. Consult the specific documentation for connection details.

## Application Settings

### UI Configuration

Customize the user interface through the admin panel:

- Theme selection (light/dark)
- Language preferences
- Timezone settings

### Performance Settings

- Query timeout values
- Cache configuration
- Connection pool settings

## Security Configuration

### CORS Settings

Configure Cross-Origin Resource Sharing (CORS) for API access.

### Rate Limiting

Set up rate limiting to prevent abuse:

- Request limits per user
- Time windows for limits
- Whitelist for trusted IPs

## Troubleshooting

### Common Configuration Issues

**Database connection failed**
- Verify connection string format
- Check database server status
- Ensure proper permissions

**Authentication errors**
- Verify NEXTAUTH_SECRET is set
- Check OAuth provider credentials
- Ensure proper redirect URLs

**Performance issues**
- Adjust cache settings
- Optimize database queries
- Monitor resource usage
